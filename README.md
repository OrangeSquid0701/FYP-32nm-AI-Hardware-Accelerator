## Experimental Results

The proposed ARM-based SoC with an integrated ANN hardware accelerator demonstrated significant improvements in performance and energy efficiency:

* **14× performance improvement** in execution time, measured in clock cycles, compared with CPU-only execution.
* **77.05% reduction in power consumption** of the accelerator IP through clock gating.
* **Python golden reference model** used to verify the hardware implementation and ensure functional correctness.

These results demonstrate that the proposed accelerator provides a high-performance and energy-efficient solution for **embedded AI applications**, while maintaining reliable hardware verification.
